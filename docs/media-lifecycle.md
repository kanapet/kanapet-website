# 产品素材生命周期规则（待独立审核与上线）

## 新图上传

- 新照片在设备上纠正方向、等比例缩小至最长边1600像素以内、压缩至500×1024字节以内，优先WebP，JPEG回退；服务端复查格式、尺寸与大小。原文件最大40MB、8000万像素；HEIC依赖浏览器解码。
- 细节图保留原比例；白底主图整理外围白色/透明边缘，方形白底、82%内容占比，不自动抠图。上传后必须人工预览，避免白色产品被误判边缘；不以压缩成功代替质量确认。
- 服务端保存上传账号、时间、原文件名、客户端声明的原文件SHA-256（安全上下文可用时）、服务端计算的成品SHA-256和处理模式。原文件指纹用于技术比对。普通局域网HTTP可能无法计算原文件指纹，明确记为 unavailable，不伪造哈希。
- 当前草稿中存在成品哈希完全相同的已上传文件时，拒绝重复上传。不同编码、相近外观和既有静态图的重复仍需人工核对。
- 上传后保存草稿，设定首图及排序、检查细节/颜色/尺寸图、视频封面，再人工发布。必须先指定新首图才能移除旧首图。

## 原图与主数据

- 上传只保存发布版本，系统不会自动备份原图。采用的原图按SKU保存在仓库外 `04-Design-Media`；上传前由操作者落实留存。
- `02-Product-Data` 保留产品业务主数据；`public/data/products.json`、确认记录与页面是发布资料。不同版本不能静默合并、覆盖或更改已确认规格。
- 不需要的原图经具体清单确认后可永久删除，不强制归档，也不自动保留重复副本。不要把唯一采用原图误当废图删除。

## 移除与永久删除

1. 从草稿移除只修改草稿；发布后才更新访客展示。移除主图前先指定新主图；移除图片时检查所有视频封面。
2. 发布不自动删除文件，本地与云端使用相同语义。内部“检查待清理素材”只列出本产品未被草稿、已发布版本或视频封面引用的上传文件。
3. 永久删除必须按文件名逐项确认。服务端复查产品归属、所有相关引用、会话/CSRF、版本号，拒绝过期清单或仍在使用的文件。
4. 云端先用条件写入记录删除标记、操作者及时间，再删除R2对象；并发保存不能恢复已标记ID。存储失败明确提示刷新重试，不宣称成功。API为 `GET /api/admin/products/:slug/cleanup`、`DELETE` 同地址，删除请求须携带 `If-Match`、`id` 和 `confirmation: 永久删除`。
5. 此功能只删除上传存储中的对象，不会删除网站仓库的 `/images/` 静态图、设备原图、其他电脑副本、Git历史或备份。静态旧图需单独生成审核清单并通过网站发布流程清理。隐藏静态图不代表文件已删除。
6. 仓库旧图清理须保护主图、图库、颜色/材质选项图、页面分享图、视频封面、已确认图片、生成脚本引用及云端草稿。完全相同、文件名带old/temp/v2、未找到文本引用都不能单独成为删除依据。
7. 批量清理前输出路径、SHA-256、大小、引用、缩略图、保留版本及清理范围，取得用户对具体清单的确认；执行前重查哈希和引用。Git历史清除需单独方案，不自动重写历史或强推。

## 本次改造边界

素材来源、权利人、授权及原创标识暂不涉及。保留技术文件指纹、处理模式、操作账号和时间。当前在独立副本验证，未推送或上线。已有的10张待辨认素材用户明确全部保留。

## 按颜色管理图片

颜色名称只读取产品资料的 colors、color_images 和 color_options，不通过素材后台修改产品规格。首次读取旧记录时补齐已有颜色图，并按原地址合并主图/图库中的相同文件；不改变已有首图。后台可按颜色筛选、为新上传照片指定颜色、将已有照片关联一个或多个颜色。每个颜色最多对应一张图片，重新指定会解除旧图片该颜色关联，但不自动删除文件。解除关联后保存，不会在重新加载时恢复。保存只改草稿，发布后颜色图片随公开素材接口生效；前台颜色按钮使用发布映射。颜色图同样受到引用、删除及版本保护。
