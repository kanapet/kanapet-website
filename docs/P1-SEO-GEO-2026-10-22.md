## Measurement implementation

- `page_view`, `whatsapp_click`, `email_click`: browser sends only enumerated event, page group and coarse source category to same-origin `/api/events`.
- `inquiry_accepted`: Worker records only after Feishu acknowledges acceptance. Client event submissions cannot create this event. Acceptance is not confirmation of a qualified lead or a human reading a message.
- Page groups: home, bird_cages, hamster_cages, product, contact, other. Product events are grouped together; model-level conversion reporting is not implemented.
- Sources: google, bing, chatgpt, perplexity, facebook, other_external, direct, internal. Current-tab session storage preserves the coarse referring-source category across internal navigation. No visitor identifier, full URL/query string, form field, email, IP or user-agent is written into this custom dataset. Normal hosting logs are independent.
- Browser DNT/GPC signals suppress browser measurement and server acceptance measurement. No analytics failure may block navigation or inquiry delivery.
- Link clicks are intent signals, not messages sent. Events count actions, not unique users. Bots, retries and blocked telemetry can affect totals. Missing referrers are direct/unknown; Google AI traffic cannot be separated from ordinary Google referrals here. Do not infer all direct visits are AI.

Credentials are not required in the repository.

Cloudflare account availability, live writes and reporting access are not verified. Confirm Analytics Engine availability in the account before publishing; inspect first live events after approved deployment. Dataset creation happens on first write. No production event or real inquiry was sent during these tests.

Reporting uses Cloudflare's Analytics Engine SQL API or dashboard with authorized account access. Suggested 28-day aggregation:

```sql
SELECT blob1 AS event, blob2 AS page_group, blob3 AS source,
       SUM(_sample_interval * double1) AS events
FROM kanapet_site_events
WHERE timestamp >= NOW() - INTERVAL '28' DAY
GROUP BY event, page_group, source
ORDER BY events DESC
```
