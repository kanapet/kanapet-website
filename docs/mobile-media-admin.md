# 手机产品素材管理：本地第一版

## 启动与登录

1. 在电脑上打开 `启动素材后台.cmd`。后台监听本机及局域网，电脑需持续运行。
2. 在电脑浏览器打开 http://127.0.0.1:8766/admin/ 。首次创建内部管理员邮箱及至少12位密码。密码仅以加盐哈希保存在本机，不写入仓库。
3. 手机和电脑连接同一 Wi-Fi，在手机浏览器打开后台显示的局域网地址（本次为 http://192.168.0.113:8766/admin/）。IP 可能变化，启动日志会列出当前地址。
4. 使用电脑上创建的账号登录。内部管理员可在“添加内部账号”中为同事创建账号；没有公开注册入口。

## 在手机上操作

选择型号 → 拍照片 / 录视频 / 从相册批量上传 → 描述照片 → 用上移、下移排序 → 为视频选择封面 → 保存草稿 → 预览草稿 → 发布到本地预览。
第一项为默认展示，通常保留产品主图，再放视频。视频按实际尺寸展示；外部视频通过比例选择配置。原有参数、B2B 页面风格和询盘按钮保留。

图片：JPG、PNG、WebP，单张最多10MB；视频：MP4、WebM、MOV，单个最多100MB，每型号最多80项。
HEIC 暂不支持，请在 iPhone 相机设置中选择“兼容性最佳”，或先导出为 JPG。MOV 播放取决于设备和编码，跨浏览器建议 MP4。本版不转码、不压缩视频。
外部链接支持 Facebook 原始视频链接、YouTube 和 Vimeo。Facebook 分享短链接需先换成原始地址。外部平台播放器不保证能显示自定义封面，后台设置的封面用于官网的视频缩略图。

## 草稿、发布和删除

上传自动保存至对应型号草稿；描述、排序、封面需保存草稿。草稿仅内部登录后可访问。
发布更新本机的产品媒体 API；本地访客只读取发布版本。没有发布的产品继续显示现有网站图片和视频。
删除先从草稿移除，已发布版本继续保留。发布后才会移除展示；文件无任何草稿或已发布引用时清理。现有官网图片不会被物理删除。
“发布到本地预览”不会修改正式官网。云存储/远程后台尚未接入，本次未创建任何收费资源。

## 访问与数据

手机连接失败时，确认同一 Wi-Fi、电脑服务仍在运行、路由器没有开启访客隔离。Windows 若阻止访问，应只为私人网络允许此 Node 服务；不要配置公网端口转发。此版本用于可信局域网，HTTP 不适合作为互联网后台。
内部账号、原始素材、排序和发布状态位于 `.local-media/`，已忽略版本管理，也不在网站公开目录。备份时先关闭后台，再复制整个目录到内部备份位置。不要只复制图片而遗漏 state.json。
服务重启后已发布数据保留，登录会话失效，需要重新登录。
后台日志：outputs/media-admin.log / outputs/media-admin-error.log。

## 验证

`node tools/test_media_server.mjs`：登录、初始账号锁定、CSRF、型号归档、上传、草稿隔离、发布、字节范围、删除及版本冲突。
`node tools/smoke_site.mjs`：现有81个地址和70款产品。
实际手机相机权限和 Facebook 播放仍需用户在对应设备上试用。
## 自动照片处理（2026-10-09）
手机和电脑在设备上处理照片，上传处理结果；原图留在用户设备，不另存云端。默认场景/细节模式保留比例；白底主图模式整理白色/透明外围留白，正方形画布82%内容占比，不自动抠图。最长边1600像素（本次默认设置），小图不放大；优先WebP，不支持则JPEG，逐级压缩/缩小，单张不超过500×1024字节。浏览器按EXIF方向解码，画布重编码清除GPS/EXIF。HEIC取决于浏览器解码能力；无法读取会提示转JPG，不上传损坏文件。
后台生成型号-image-序号-唯一短码.ext，保留稳定素材ID地址，响应Content-Disposition使用规范文件名；名称/尺寸从服务端素材元数据恢复，不能由保存草稿伪造。云端R2对象仍使用内部ID键。服务端验证JPEG/PNG/WebP尺寸与500KB限制；既有图片不改写，新图必须经过处理。已存在的旧上传照片不会批量改写，需选原图重新上传。
